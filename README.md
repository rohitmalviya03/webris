# WebRIS — Cloud Radiology Information System

A complete SaaS Radiology Information System (RIS) with two separate portals: **Diagnostic Center Portal** and **Radiologist Portal**.

## Architecture

```
webris/
├── backend/          # Spring Boot 3 (Java 17)
├── frontend/         # React 18 + TypeScript + Tailwind CSS
├── docker/           # Orthanc config, Nginx config
└── docker-compose.yml
```

## Tech Stack

| Layer       | Technology |
|-------------|-----------|
| Frontend    | React 18, TypeScript, Tailwind CSS, Vite |
| Backend     | Java 17, Spring Boot 3.2, Spring Security + JWT |
| Database    | PostgreSQL 15 |
| PACS        | Orthanc DICOM Server |
| Viewer      | OHIF (via iframe) |
| Deployment  | Docker + Docker Compose |

## Quick Start (Docker)

```bash
# Clone and start all services
git clone <repo>
cd webris
docker-compose up --build

# Services will be available at:
# Frontend:   http://localhost:3000
# Backend API: http://localhost:8080/api
# Orthanc:    http://localhost:8042
# Nginx proxy: http://localhost:80
```

## Workflow

```
Patient Registration → Study Order → Billing
       ↓
DICOM Machine → Orthanc PACS (AET: ORTHANC, Port: 4242)
       ↓
RIS auto-matches by Accession Number (= Lab No)
       ↓
Case Assignment to Radiologist
       ↓
Radiologist: View DICOM + Write Report → Submit
       ↓
Approver: Review → Approve / Reject
       ↓
Final Report PDF (Download / Print / Email)
```

## DICOM Configuration

Configure your CT/MRI scanner to send to:
```
AE Title : ORTHANC
Host     : <server-ip>
Port     : 4242
```

The Accession Number field on the scanner should match the **Lab No** generated by the RIS (e.g., `LAB202606190001`).

## Local Development

### Backend

```bash
cd backend
# Start PostgreSQL first (or use Docker)
docker run -d -p 5432:5432 -e POSTGRES_DB=risdb -e POSTGRES_USER=risuser -e POSTGRES_PASSWORD=rispassword postgres:15

mvn spring-boot:run
# API available at http://localhost:8080/api
```

### Frontend

```bash
cd frontend
npm install
npm run dev
# App at http://localhost:5173
```

## API Reference (key endpoints)

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/auth/login` | Login, returns JWT |
| GET  | `/api/dashboard` | Center dashboard stats |
| POST | `/api/patients` | Register patient |
| GET  | `/api/patients?search=` | Search patients |
| POST | `/api/studies` | Create study order |
| GET  | `/api/studies?status=` | List studies |
| POST | `/api/billing` | Create invoice |
| POST | `/api/assignments` | Assign case to radiologist |
| GET  | `/api/assignments/my-cases` | Doctor's assigned cases |
| POST | `/api/reports/study/{id}` | Save/submit report |
| POST | `/api/reports/{id}/approve` | Approve report |
| GET  | `/api/reports/{id}/pdf` | Download PDF report |
| POST | `/api/studies/orthanc-link` | Link DICOM study to RIS |

## User Roles

| Role | Access |
|------|--------|
| SUPER_ADMIN | All centers, user management |
| CENTER_ADMIN | Own center full access |
| RECEPTIONIST | Patient registration, study orders |
| TECHNICIAN | Study status updates |
| RADIOLOGIST | Assigned cases, DICOM viewing, reports |
| REPORT_APPROVER | Report approval workflow |

## Security

- JWT authentication (24h expiry, configurable)
- Role-based access control (Spring `@PreAuthorize`)
- CORS configured for frontend origin
- All passwords BCrypt-hashed
- Audit log for critical actions

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `SPRING_DATASOURCE_URL` | `jdbc:postgresql://postgres:5432/risdb` | DB URL |
| `JWT_SECRET` | (change in prod!) | JWT signing secret |
| `JWT_EXPIRATION` | `86400000` (24h) | Token expiry in ms |
| `ORTHANC_URL` | `http://orthanc:8042` | Orthanc URL |
| `ORTHANC_USERNAME` | `admin` | Orthanc basic auth |
| `ORTHANC_PASSWORD` | `admin` | Orthanc basic auth |
